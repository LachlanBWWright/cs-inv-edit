# Item details panel design defence

The details panel exists to prevent context loss. Once a user selects an item, the most decision-critical attributes are gathered into one stable panel: finish identity, wear, sticker count, price band, and routing state.

This panel uses a larger hero treatment than the inventory cards because the selected item should feel meaningfully distinct from the browsing state. The stronger visual focus helps users confirm they are planning actions against the correct item.

The explanatory guardrail copy is intentional. The surrounding research makes it clear that item edits should be treated cautiously, so the UI uses the details panel to reinforce deliberate review behaviour instead of presenting mutation as a casual one-click action.
