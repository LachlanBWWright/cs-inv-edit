# Sticker workshop design defence

The sticker workshop uses **named presets** instead of raw numeric controls because this repository does not have live data or a validated production mutation path. Presets still give the user visible choices while keeping the placeholder experience honest.

The preview notes sit directly beneath the preset selector so the user can understand the likely outcome without opening a secondary modal or drawer. This keeps the workflow lightweight on mobile and highly legible on desktop.

The action button is labelled as a review queue rather than an apply action. That wording is important because it matches the documented risk posture: the interface is showing a controlled plan, not encouraging blind automation.
