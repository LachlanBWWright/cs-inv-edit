# Inventory grid design defence

The inventory grid uses medium-density cards rather than a table because the user must compare finish, wear, sticker count, readiness, and routing state at a glance. A card layout makes it easier to keep the information hierarchy intact across both desktop and mobile breakpoints.

Each card places the most recognisable cues first: weapon type, weapon name, finish, and collection. Secondary metadata is pushed into compact chips so the surface remains scannable instead of noisy.

The queue action sits inside the card because trade-up review is one of the primary tasks. Keeping it adjacent to the item removes unnecessary pointer travel on desktop and keeps mobile interactions single-context.
