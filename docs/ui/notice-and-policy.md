# Notice banner and policy card design defence

The notice banner exists to make system feedback unavoidable. It uses a single surface that can shift between informational, success, and warning tones so the user always knows where to look after triggering a review action.

The policy card is visually separated from the operational panels because it serves a different job: it frames the whole interface in terms of safety and compliance. Keeping it persistent near the top prevents the user from interpreting the app as an unqualified automation tool.

This separation is especially important in a cross-platform app. A desktop window can make software feel more authoritative, and a mobile shell can make actions feel deceptively casual, so the policy framing needs to stay visible across both contexts.
