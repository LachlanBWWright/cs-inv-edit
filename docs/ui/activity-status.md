# Activity rail and status design defence

The activity rail is designed as a short, high-signal feed instead of a full audit table. The goal is to help the user understand what changed recently without overwhelming the main interface.

Status cards use three tones only: stable, watch, and risk. This limited palette keeps the signalling consistent and prevents the dashboard from becoming visually noisy.

Placing activity and status on the right rail works well on desktop because those panels support the main work rather than competing with it. On mobile, they stack below the primary work zones so the user still reaches the decision-critical controls first.
