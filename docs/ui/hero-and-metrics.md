# Hero and metrics design defence

The hero section establishes the app's tone immediately: this is a working control surface, not a promotional homepage. The copy is concise, operational, and anchored to the placeholder-safe nature of the data.

The metric cards are intentionally small and high contrast. They give the user immediate orientation on scope, readiness, storage pressure, and session timing without forcing a read through longer explanatory text.

On desktop, these metrics create a quick scanning lane beside the hero copy. On mobile, they wrap into two columns so the summary remains compact and does not dominate the first screen.
