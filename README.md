# cs-inv-edit

A responsive SolidJS control surface for researching and planning Counter-Strike inventory edits, with placeholder-safe workflows for sticker preparation, trade-up review, storage orchestration, and operational status tracking.

## Platform shells

- **Web**: SolidJS + Vite + Tailwind CSS
- **Desktop**: Electron shell around the shared web build
- **Mobile**: Capacitor wrapper around the shared web build

## Quality gates

- `npm run lint`
- `npm run test`
- `npm run build`
- `npm run desktop:dev`
- `npm run mobile:sync`

## UI documentation

The UI design rationale lives in `/docs/ui` and the captured review screenshots live in `/docs/ui/screenshots`.
